Usage guide
  1. Mode — the four checkboxes are mutually exclusive. Leave all unchecked for a full result.
  2. Match info — set BanNums (4 or 5), tick Game in Progress to leave length and winner blank, and tick Change Side to swap the two teams' input blocks.
  3. Side and winner — click Team1Side to toggle blue/red; Team2 takes the opposite side automatically. Click Winner to toggle Team1/Team2.
  4. Length — MM and SS accept digits only and are padded on blur; leaving them empty produces 00:00.
  5. Heroes — type a full name or an alias and pick from the list. A red border means no match, a yellow border means several matches, and a hero filled into more than one box is highlighted.
  6. Keyboard — Tab and Shift+Tab move between inputs and buttons; ↑ / ↓ move through the suggestion list; Enter confirms the highlighted entry; Esc closes the list.
  7. Alias management — edit aliases, add or delete heroes via “Search/Update Hero Alias or Add Hero”. Changes stay in this browser and merge with updated data.json automatically; use Clear LocalStorage to reset.
